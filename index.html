Nginx Performance
Tips
worker_processes: Set to auto to match CPU cores

worker_connections: Max simultaneous connections per worker. 1024–4096 for busy servers

keepalive_timeout: How long to keep idle connections open. 15–65 sec is typical

client_max_body_size: Max file upload size (e.g. 100M, 1G)

gzip: Compresses responses — reduces bandwidth ~70%

server_tokens: Set off to hide nginx version from headers
PHP Settings
Tips
memory_limit: Max RAM per PHP script. WordPress needs at least 128M, heavy sites 256M+

max_execution_time: Max seconds a script can run. Increase for slow imports/exports

upload_max_filesize: Must be ≤ post_max_size and Nginx client_max_body_size

post_max_size: Max total POST data size — set slightly larger than upload limit

Use M for megabytes, G for gigabytes (e.g. 512M, 2G)
PHP-FPM Pool
Tips
pm = dynamic: Spawns workers on demand (best for most sites)

max_children: Max PHP workers. Each uses ~30–50MB RAM. Don't exceed available RAM

start_servers: Workers spawned at startup

min/max_spare: Idle workers kept alive. Higher = faster response, more RAM

max_requests: Restart worker after N requests — prevents memory leaks. 500–1000 is good

request_terminate_timeout: Kill worker if request takes longer (0 = disabled)
MySQL Settings
MySQL will restart briefly
Tips
max_connections: Max simultaneous DB connections. Default 151 is fine for local

innodb_buffer_pool_size: Most important MySQL setting — cache for InnoDB data. Set to 50–70% of available RAM for DB servers (e.g. 512M, 1G)

slow_query_log: Set to 1 to log slow queries for debugging

long_query_time: Queries slower than this (seconds) get logged

max_allowed_packet: Max size of a single MySQL packet (affects large imports)

Sudo Permissions

This panel runs system commands with sudo. Add this file to allow passwordless access:

sudo tee /etc/sudoers.d/server-panel <<'EOF'
# Allow server-panel to control services and edit nginx configs
YOUR_USER ALL=(ALL) NOPASSWD: /usr/bin/systemctl start nginx
YOUR_USER ALL=(ALL) NOPASSWD: /usr/bin/systemctl stop nginx
YOUR_USER ALL=(ALL) NOPASSWD: /usr/bin/systemctl restart nginx
YOUR_USER ALL=(ALL) NOPASSWD: /usr/bin/systemctl reload nginx
YOUR_USER ALL=(ALL) NOPASSWD: /usr/bin/systemctl start mysql
YOUR_USER ALL=(ALL) NOPASSWD: /usr/bin/systemctl stop mysql
YOUR_USER ALL=(ALL) NOPASSWD: /usr/bin/systemctl restart mysql
YOUR_USER ALL=(ALL) NOPASSWD: /usr/bin/nginx -t *
YOUR_USER ALL=(ALL) NOPASSWD: /bin/cp /tmp/_panel_* /etc/nginx/*
YOUR_USER ALL=(ALL) NOPASSWD: /bin/cp /etc/nginx/nginx.conf /etc/nginx/nginx.conf.bak
YOUR_USER ALL=(ALL) NOPASSWD: /bin/ln -sf /etc/nginx/sites-available/* /etc/nginx/sites-enabled/*
YOUR_USER ALL=(ALL) NOPASSWD: /bin/rm -f /etc/nginx/sites-enabled/*
YOUR_USER ALL=(ALL) NOPASSWD: /usr/bin/tail * /var/log/nginx/*
YOUR_USER ALL=(ALL) NOPASSWD: /usr/bin/mysql
EOF
